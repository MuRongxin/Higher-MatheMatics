## 泰勒公式

我们可以先这样简单的了解泰勒公式：一个复杂函数的图像，可以由多个简单函数的图像叠加而成。
我们现在用 Sin x 来具体说明一下：
我们先来看在 x=0 处的情况：
在 x=0 这一点，最接近Sinx图像的是什么？

### 零阶近似 (Level 0 Imitation) - 模仿“位置”
最简单的就是一个常数- y=0,这样它它至少在 x=0 点和 sin x 一样。

【绘图】
这第一个简单函数我们就记为：让 P₀(x) = 0（一个常数）。要让

评价：“不过这个模仿太糟糕了！零阶逼近只在这个点本身是完全精确的，其他地方完全不像。它连 sin x 是上升还是下降都不知道。” 不过他确保了展开点上的“位置”匹配


 ### 一阶近似 (Level 1 Imitation) - 模仿“趋势”
让它有上升的趋势？我们需要一个一次函数 P₁(x) = c₀ + c₁x  
条件：

    (a) 值相等： P₁(0) = sin(0) => c₀ = 0

    (b) 导数相等 (斜率相等)：

        (sin x)' = cos x => 在0点的斜率是 cos(0) = 1。

        P₁’(x) = c₁ => 令 c₁ = 1

结果：P₁(x) = 0 + 1 * x = x

画图：在图上画出直线 y = x。

评价：“好多了！在原点附近，这条直线和 sin x 的曲线贴合得很近。它终于有了正确的‘方向’。但它还是直的，而 sin x 是会弯曲的。”

 ### 二阶近似 (Level 2 Imitation) - 尝试模仿“弯曲”

    问题：如何让它弯曲？我们升级到二次函数 P₂(x) = c₀ + c₁x + c₂x²。

    条件：

        (a) 值相等： P₂(0) = 0 => c₀ = 0

        (b) 一阶导相等： P₂’(x) = c₁ + 2c₂x => P₂’(0) = c₁ = 1 (因为斜率是1)

        (c) 二阶导相等 (弯曲程度相等)：

            (sin x)'' = -sin x => 在0点的二阶导是 -sin(0) = 0。

            P₂''(x) = 2c₂ => 令 2c₂ = 0 => c₂ = 0

    结果：P₂(x) = x

    发现：“太有趣了！二次项系数消失了。这说明在 x=0 点，sin x 的‘弯曲’是0（它在这个点其实是拐点，从向上弯变为向下弯）。所以二阶近似和一阶近似是一样的。我们需要更高阶的工具来捕捉它的弯曲特性。”



### 三阶近似 (Level 3 Imitation) - 抓住“灵魂”

    问题：让我们试试三次多项式 P₃(x) = c₀ + c₁x + c₂x² + c₃x³。

    条件：

        (a) 值相等： c₀ = 0

        (b) 一阶导相等： c₁ = 1

        (c) 二阶导相等：

            P₃''(x) = 2c₂ + 6c₃x

            P₃''(0) = 2c₂，令其等于 -sin(0) = 0 => c₂ = 0 (再次验证)

        (d) 三阶导相等：

            (sin x)''' = -cos x => 在0点的三阶导是 -cos(0) = -1。

            P₃'''(x) = 6c₃ => 令 6c₃ = -1 => c₃ = -1/6

    结果：P₃(x) = x - (1/6)x³

    画图 & 演示：

        画出 y = x - x³/6 的图像。

        将其与 y=sin x 和 y=x 对比。

        神奇的时刻到了！ 学生们会清楚地看到，这条三次曲线在原点附近比直线 y=x 更长时间地贴合 sin x 曲线，它开始“弯”向x轴，就像真正的 sin x 一样！

        可以计算 sin(0.5) ≈ 0.4794， P₃(0.5) = 0.5 - (0.125)/6 ≈ 0.4792。非常接近！



函数值决定了多项式在该点的“位置”，一阶导数决定了“斜率”或“方向”，二阶导数决定了“弯曲程度”或“凹凸性”，更高阶的导数则描述了更精细的曲率变化

通过上面这些步骤，我们就可以得出，至少在 x=0 处，sin x 的值、斜率、弯曲程度和这个函数y = x - x³/6一致。我们可以通过研究这个简单的多项式，进而去研究 sin x 在x=0处的性质。

这其实就是泰勒公式在做的事情。

那sinx在 x=0 处的泰勒展开其实是有现成的公式可以用的，在x=0处的泰勒展开其实也叫做麦克劳林公式
   

所以，在极限问题中，函数在一点附近的行为可以用多项式逼近。多项式比复杂函数（如 sin⁡x,ex,ln⁡(1+x)sinx,ex,ln(1+x)）更容易计算。
泰勒公式特别适合多个函数复合或相乘除的极限。特别是x→0（或可化为 x→0）的未定式（如 0/00/0 型）要重点考虑泰勒公式的运用。


我们主要用到的是
带佩亚诺余项的泰勒公式（麦克劳林形式）：
f(x)=f(0)+f′(0)x+f′′(0)2!x2+⋯+f(n)(0)n!xn+o(xn)(x→0)


常见函数的展开式（必须熟记）:


$\lim_{x\to 0}\frac{\mathrm{e}^{x}-1-x}{x^{2}}$
而 o(x2)  是比 x2  高阶的无穷小，除以 x2  后变成比常数 1  高阶的无穷小，即一个趋于 0  的量，记作 o(1) 。


例子2：求极限 $\lim_{x\to 0}\frac{\sin x-x}{x^{3}}$ 。

$\sin x = x - \frac{x^3}{3!} + o(x^3)$
$$
\sin x - x = \left(x - \frac{x^3}{3!} + o(x^3)\right) - x = -\frac{x^3}{6} + o(x^3) \\
\frac{\sin x - x}{x^3} = \frac{-\frac{x^3}{6} + o(x^3)}{x^3} = -\frac{1}{6} + o(1) \\
\lim_{x\to 0}\left(-\frac{1}{6} + o(1)\right) = -\frac{1}{6}\\
\boxed{-\frac{1}{6}}
$$

分母阶数为 44，需展开到 x4x4。

为什么这里不写$o(\frac{x^4}{4})$而是写$o(x^4)$呢，因为常数因子不影响无穷小的阶,始终要注意，余项只需要指明“最低阶数”，它不进行实际的运算，而是有具体的指代意义；

两个无穷小 o 怎么变成了一个：两个同阶小 o  相加或相减，结果仍是同阶小 o 。两个余项合并后，符号和系数都不影响最终的无穷小阶数




通过这个例子更好的理解余项：$\lim_{x \to 0} \frac{\ln(1+\sin x)-x}{x^2}$
皮亚诺余项：是一个“定性描述”，而不是一个具体算出来的公式，用来表示误差或者说展开的精确度的。
所有“可忽略”的项，整体记为 o(x^2) ，因为它们与 x^2  的比值都趋于 0。于是
